## Flutter app (mobile)

This folder is a Flutter project scaffold. If Flutter is not installed on this PC yet, install it first, then from this folder run:

```bash
flutter pub get
flutter run
```

### Backend URL
In development the app calls the backend at `http://localhost:4000`.

If you run on a physical device/emulator, you may need to change the base URL in `lib/src/core/api/api_client.dart`.
